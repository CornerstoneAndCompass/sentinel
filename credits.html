==============================

This file records code and data in this project that originates elsewhere, and
the terms it arrives under. It exists because the MIT licence requires the
copyright notice to travel with the code, and because a board that labels its
own data sources should be able to say where its code came from too.


God's Eye View
--------------
https://github.com/bilawalsidhu/gods-eye-view

Portions of the 3D globe view (globe.html) are derived from God's Eye View,
used under the MIT licence reproduced below.

What is derived, specifically:

  * The aircraft classification scheme — the mapping from ICAO type codes to
    airframe categories (fastjet, quadjet, widebody, turboprop, helicopter,
    glider, bizjet, light, UAV, airliner), and the fallback to ADS-B emitter
    category when the type code is unknown. This is domain knowledge, not
    something worth re-deriving.

  * The approach to contact symbology: per-category SVG silhouettes rasterised
    to fixed-size bitmaps rather than scaled by the GPU, with colour applied as
    a billboard tint rather than baked into the artwork.

The silhouette artwork itself is our own, and the surrounding rendering,
dead-reckoning, HUD and data plumbing are original to this project.

Explicitly NOT taken: the datasets that project bundles. Its author notes that
third-party data — TeleGeography submarine cables, OpenStreetMap extracts, NASA
fire data and 3D models — is excluded from its MIT grant and carries its own
terms. None of it is used here.
